STANDEE MAKER PRIVACY POLICY (Information notice pursuant to articles 13 and 14 of Regulation (EU) 2016/679) Version 2.2 - 1 October 2026 (Beta) SUMMARY Standee Maker operates on the user's computer. Images, SVG files, STL files and information on how the program is used are not transmitted to the Controller or to any third party. During the Beta no licence is needed and the program does not connect to the internet for licensing. The program connects only (i) from the commercial release, to activate, release and periodically validate a licence key, and (ii) at most once a day, to check whether a new version is available; the latter check can be disabled. The program has no analytics, telemetry or crash reporting, and neither it nor the website uses advertising or cookies. During the Beta only, the website counts visits in aggregate with GoatCounter, to find out how much interest there is in the project (clause 3.4). If you ask to join the launch list, or send feedback, by e-mail, your message is used only for that purpose (clause 3.6). 1. DATA STORED ONLY ON THE USER'S COMPUTER 4.1 The following data is stored locally by the Software and is not accessible to, or processed by, the Controller: (a) the images imported into the library and the SVG, STL and 3MF files generated, in the folder Documents\Standee Maker; (b) the file license.json, in the folder %LOCALAPPDATA%\Standee Maker, containing the licence key, the activation identifier, the type of licence, the date of the last validation, the date of activation, and the progress of the trial period, including the names of the subjects processed during the trial; (c) a copy of the trial progress (days of use and names of the subjects processed during the trial, without any licence key), in the Windows registry under HKEY_CURRENT_USER\Software\Standee Maker; (d) the file errors.log, in the folder Documents\Standee Maker, which records technical information on errors and may contain file names and folder paths, including the Windows account name. 4.2 The data under (b) and (c) is sealed with a key derived from the computer's installation identifier, so as to detect alteration. It is used exclusively by the Software on the user's computer. 4.3 The function "Copy diagnostics" places on the clipboard a report containing the program version, the activation label, the type of licence, the last four characters of the licence key, the Windows version, the screen size, the program folders (with the user profile folder replaced by %USERPROFILE%) and the most recent entries of errors.log. The report is not transmitted by the Software; it reaches the Controller only if the user chooses to send it. 4.4 Uninstalling the Software does not delete the data under (a) and (d) unless the user so chooses when prompted, and does not delete the data under (b) and (c). 5.
